# Chef cuisinier

Agent Claude Code spécialiste de la cuisine. Il répond en français sur les recettes, les techniques,
la pâtisserie, les ingrédients, les substitutions, la nutrition, la conservation et les accords mets-vins.

- Fichier : `.claude/agents/chef-cuisinier.md`
- Créé à l'origine dans le dépôt `Cours`.

## Utilisation

Copie `.claude/agents/chef-cuisinier.md` dans le `.claude/agents/` de ton projet (ou dans `~/.claude/agents/`),
lance `claude`, puis pose ta question, par exemple :

> Utilise chef-cuisinier : comment réussir une pâte à choux ?
